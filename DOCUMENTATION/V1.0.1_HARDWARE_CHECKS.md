# V1.0.1 physical-console verification

These checks supply the final performance evidence that an emulator cannot provide. Use the same stock-clock console, flash cartridge and sound settings for both versions. Back up cartridge saves if required by your cartridge software.

1. Load `REFERENCE_V1.0.0/Batman_M66_Anti_Farming_Diagnostic_4MB.ngc`. At the title screen press B for the hardware test menu. Left/Right selects the level, A toggles sound, and B runs the fixed 300-step replay. Do not provide gameplay input during the replay.
2. Photograph every report page: Left/Right changes the report page; A repeats; B returns to the test menu. Record actual source-complete updates, presents, refreshes, maximum/histogram gaps, peak sprites, overflows, pattern/read/descriptor bytes, cache activity, DMA blocks and audio underruns. A 300-step test is a fixed workload, not a speed setting.
3. Run levels 1, 2, 4 and 5 at least three times with sound ON and three times with sound OFF. Check level 3 as the control. Use the same starting state each time. Note any RTC warning or timeout; do not treat an incomplete trial as a valid speed result.
4. Repeat with `OUTPUT/Batman_V1.0.1_Diags.ngc`, whose heading says V1.0.1. Alternate old/new trials if possible. Compare the median refresh count for the same completed work and sound state. Throughput gain = `(old_refreshes/new_refreshes - 1) * 100%`. Use refresh counts for the comparison rather than rounding the displayed rate.
5. On the normal ROM, play busy scenes in all five levels. Check road markers and off-screen objects, Batmobile grapples, Batwing edges, platform ropes/projectiles, pause/menus and stage transitions. Listen for music pitch changes, interruptions or missing effects. Diagnostic replay coverage is not full-game playthrough coverage.
6. Test manual Save, power off/on, Continue and stage-clear autosave. A saved next-stage start should remain after a cold boot. Try deaths around checkpoints and confirm previously credited rewards cannot be farmed. Check cheat-unlocked and more-than-three-starting-life runs remain unranked.
7. With an eligible positive record, check overall and stage QR upload. Reset Records, cold boot, and confirm best/last remain zero and zero-point QR upload is blocked. The menu and endgame credits should include Hardhat Warrior and the website.

The V1.0.1 emulator tests passed, but no new physical-console measurements are claimed. Earlier M12R2/M15/M17/M21 photos refer only to those builds and cannot establish V1.0.1 speed.
